# Velours

App de rencontre pour les filles qui aiment les filles. Site web statique (HTML/CSS/JS, sans build) avec comptes, profils, photos et messages via Supabase.

- `config.js` : adresse du projet Supabase et clé publique (publishable). Vide = mode démo.
- `supabase-schema.sql` : à exécuter une fois dans Supabase → SQL Editor.
- Mise en ligne automatique sur GitHub Pages à chaque push (`.github/workflows/pages.yml`).
